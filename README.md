# NEWTON PLATFORM 🚀

A modern, mobile-first web application for a **digital equipment leasing ecosystem**.
Built with **vanilla HTML, CSS, and JavaScript** — no frameworks, no dependencies.

Users can register, log in, purchase equipment packages, track earnings, manage
pending transactions, and chat with a live support manager — all in a sleek,
red-themed mobile interface.

---

## ✨ Features

- 🔐 **User Authentication** — Login & registration flow
- 💰 **Account Balance Dashboard** — Live balance display in UGX
- ⚙️ **Equipment Series Store** — Browse and purchase RS-1, RS-2, RS-3 machines
- 📄 **Transaction Bills** — Track pending requests and cancel them anytime
- 💬 **Live Manager Chat** — Simulated support chat with auto-replies
- 👤 **Profile & Settings** — Personal info, security, notifications
- 🎨 **Animated Particle Background** — Dynamic canvas-based network effect
- 📱 **Mobile-First Design** — Fixed 440px layout mimicking a smartphone app
- 🎭 **Modal System** — Reusable modals for payments, alerts, and purchases
